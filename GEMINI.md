# Baserow

The `baserow` MCP server connects to one Baserow workspace, with the tools the user
allowed. Before using it, read the `baserow-basics` skill. Also use `baserow-databases`
for databases, tables, fields and views, `baserow-automations` for workflows,
`baserow-dashboards` for dashboards, `baserow-app-builder` for application builders,
and `baserow-workspace` for search, row comments and the audit log.
